# Diffuse Enterprise - Releases

Official release artifacts for Diffuse Enterprise: Debian packages,
the offline bundle, and their SHA-256 digests.

The latest release is always available at stable URLs under
`releases/latest/download/`. Install instructions ship with every
release and at https://docs.diffuse-systems.com

This repository intentionally contains no source code. The archives
GitHub attaches to each release ("Source code") therefore contain
only this README.
